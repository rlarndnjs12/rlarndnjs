# Trip Mate

파란색 테마의 여행 안내 사이트. 현재 탭 전용 임시 회원가입·로그인과 이동 방법, 호텔 추천, 맛집 추천 페이지를 제공합니다.

## 실행 및 배포

Node.js 24.x에서 `npm start`로 실행합니다. 기본 포트는 3001입니다. `npm test`로 테스트하고 `npm run build`로 public/에 정적 파일을 만듭니다. Vercel은 vercel.json의 설정으로 빌드합니다.

## 여행 지점 입력 흐름

로그인·프로필 입력 후 index.html에서 출발지와 도착지를 설정합니다. 다음 단계로 진행하면 transport.html의 이동 방법 화면이 열립니다. 호텔·맛집 페이지에도 입력 위치가 유지되며 각 페이지의 출발지·도착지 변경 버튼으로 입력 화면에 돌아갈 수 있습니다. 입력 화면에서 저장하면 원래 보던 페이지로 돌아옵니다.

## Google 지도 검색

- 이동 방법: 출발지와 도착지를 입력하고 대중교통·자동차·도보·항공을 선택합니다. 항공은 출발·도착 도시 또는 공항으로 Google 항공편을 검색하며 날짜·공항은 해당 서비스에서 확인합니다. 각 카드와 검색 버튼은 Google Maps URLs의 travelmode=transit/driving/walking으로 연결합니다.
- 호텔 추천: 도착지 주변 호텔·리조트·게스트하우스를 Google 지도에서 검색합니다.
- 맛집 추천: 도착지 주변 음식점·카페·패스트푸드를 Google 지도에서 검색합니다.
- 지도 검색 링크에는 API 키나 서버 데이터베이스가 필요하지 않습니다. 입력한 위치와 검색어는 링크를 열 때 Google로 전달됩니다.
- 검색 결과는 Google 지도에서 확인합니다. 사이트 자체에 실시간 장소 목록·평점·가격을 표시하거나 경로를 계산하지 않습니다.
- 한국 등 지역에 따라 Google 지도의 자동차·도보 경로가 제공되지 않을 수 있습니다. 이동 결과 패널에서 네이버 지도 지역 검색도 제공합니다. 이는 자동 경로 계산을 보장하는 기능이 아닙니다.
- 검색 결과 패널에 직접 누를 수 있는 지도 링크도 남아 있으므로 새 탭이 열리지 않으면 해당 링크를 사용하세요.
- 호텔·맛집 페이지는 /api/recommendations를 호출하지 않습니다. 저장소에 남아 있는 이전 OSM API는 화면에서 사용하지 않는 레거시 엔드포인트입니다.

## 현재 탭 전용 임시 회원가입

이름(예: 홍길동), 이메일, 비밀번호(8~128자), 비밀번호 재입력으로 가입한 뒤 같은 탭에서 이름과 비밀번호로 로그인합니다. 로그인 후 닉네임·성별·나이를 입력합니다.

계정·프로필은 서버로 전송하지 않고 sessionStorage에만 보관합니다. 비밀번호는 무작위 salt와 PBKDF2-SHA256(600,000회) 해시로 보관합니다. 로그아웃 후 같은 탭에서 다시 로그인할 수 있습니다. HTTPS 또는 localhost가 필요합니다.

새 탭/다른 기기에서는 계정을 사용할 수 없습니다. 탭을 닫으면 일반적으로 사라지지만 브라우저 탭 복제/복원 기능은 정보를 복사·복원할 수 있습니다. 확실한 삭제는 임시 정보 삭제 버튼을 사용하세요. 비밀번호를 잊으면 이메일 복구 대신 임시 정보를 지우고 다시 가입합니다.

서버 인증이 아닌 체험 기능이므로 민감한 데이터 접근 제어에 사용하지 마세요. 임시 가입에는 API 키나 계정 저장소가 필요하지 않습니다.
